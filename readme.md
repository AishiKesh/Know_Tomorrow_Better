-is a modern ai astrology engine chatbot built to bring high-precision celestial data to life. It features full interactive birth signs calculation, daily transit tracking, zodiac compatibility analysis, and personalized horoscope feeds—all rendered through clean visual components and an intuitive user interface.

The Tech Stack
Behind the celestial crystal ball is a modern, robust, and highly reliable Python stack. Let’s break down the key ingredients:

Python (v3.10+): The bedrock of our calculations, environment setups, and AI orchestrations.

Streamlit: For rendering the immersive cosmic dark-themed interface. It turns data scripts into an interactive, sleek web application with custom CSS injected styling in minutes. It also has a mind of its own, hence the occasional required restart.

Groq Cloud API & LangChain (via ai_services): The ultra-fast "brain" of the Oracle. Powered by Groq's high-speed LPU inference engine, it acts as our master astrologer—digesting natal coordinates and translating complex cosmic data into deep, real-time interactive readings.

Astronomy Engine (astronomy_engine): The precise mathematical foundation used to calculate high-accuracy ephemeris data, natal positions, Sun and Moon signs, and active planetary transits on demand.

ReportLab / PyPDF (via ai_services): The dynamic PDF generation engine responsible for rendering and exporting comprehensive, downloadable astrology reports for users.

python-dotenv: The security layer managing environment variables, ensuring API keys like GROQ_API_KEY remain safely isolated from the core application logic.
